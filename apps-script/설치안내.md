# 모의고사 분석 — 구글 시트 연결 (원장이 한 번만)

준비물: 학원 구글 계정 로그인, `Code.gs` 파일(이 폴더에 있음). 약 10분.

## 1. 시트 만들기
1. 학원 구글 계정으로 https://sheets.google.com 접속
2. 왼쪽 위 **빈 스프레드시트(+)** 클릭
3. 왼쪽 위 '제목 없는 스프레드시트'를 눌러 **메이트 모의고사** 로 이름 바꾸기

## 2. 코드 붙여 넣기
1. 위 메뉴 **확장 프로그램 → Apps Script** 클릭 (새 탭이 열림)
2. 가운데 편집 창에 있는 `function myFunction() { }` 를 **전부 지우기** (Ctrl+A → Delete)
3. `Code.gs` 파일 내용을 **전부 복사해서 붙여 넣기** (Ctrl+A → Ctrl+C → 편집 창에 Ctrl+V)
4. 위쪽 **💾 저장 아이콘(프로젝트 저장)** 클릭
5. 왼쪽 위 '제목 없는 프로젝트'를 눌러 **메이트 모의고사 서버** 로 이름 바꾸기

## 3. 탭 만들기·비밀번호 정하기
1. 시트 탭으로 돌아가 **새로 고침(F5)** → 위 메뉴에 **메이트 모의고사** 가 생김 (10초쯤 걸릴 수 있음)
2. **메이트 모의고사 → ① 처음 설정 (탭 만들기)** 클릭
3. '승인 필요' 창이 뜨면: **계속** → 학원 계정 선택 → **고급** → **메이트 모의고사 서버(으)로 이동(안전하지 않음)** → **허용**
   (직접 만든 코드라서 나오는 경고입니다)
4. 승인 후 **① 처음 설정**을 한 번 더 클릭 → '처음 설정 완료' 창 → 확인
5. **메이트 모의고사 → ② 비밀번호 설정** → 직원 비밀번호(조교·강사용) 입력 → 확인 → 확정 비밀번호(원장용, 직원 것과 다르게) 입력 → 확인

## 4. 웹 앱으로 배포
1. Apps Script 탭으로 가서 오른쪽 위 **배포 → 새 배포** 클릭
2. '유형 선택' 옆 **⚙ 톱니바퀴 → 웹 앱** 선택
3. 설명: `1단계` (아무거나)
4. **다음 사용자로서 실행: 나(학원 계정)**
5. **액세스 권한이 있는 사용자: 모든 사용자** ← 꼭 이것 (비밀번호가 있어서 괜찮음)
6. **배포** 클릭 → (승인 창이 또 뜨면 3-3과 같이 허용)
7. 나온 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`) 옆 **복사** 클릭 → 완료

## 5. 연결 확인
1. 복사한 주소를 새 탭 주소창에 붙여 넣고 Enter → "메이트 모의고사 서버가 작동 중입니다" 가 나오면 성공
2. 메이트랩 모의고사 분석 화면 → 맨 아래 **시트 연결 주소** → 주소 붙여 넣기 → **이 주소로 연결** → 비밀번호로 입장해 시험 하나 등록해 보기 → 시트 '시험' 탭에 한 줄이 생기면 끝
3. 그 주소를 Claude에게 알려 주면 사이트에 넣어 모든 컴퓨터에 적용합니다.

## 나중에 코드를 바꿀 때
코드를 새로 붙여 넣은 뒤 **배포 → 배포 관리 → ✏ 연필 → 버전: 새 버전 → 배포**. (주소는 그대로 유지됨. '새 배포'를 누르면 주소가 바뀌니 주의)

## 알아 둘 것
- 성적 시트는 학원 계정에만 둡니다. 조교에게 시트를 공유하지 않습니다.
- 시트에서 직접 고쳐도 됩니다(예: 학생 이름 오타, '숨김' 칸에 Y → 목록에서 숨김). 머리줄(1행)과 탭 이름은 바꾸지 마세요.
- 비밀번호를 10번 틀리면 10분 동안 모든 입장이 잠깁니다.
